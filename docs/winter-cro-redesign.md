# 윈터캠프 랜딩 CRO 리디자인 근거 (2026-07-31)

목표: "좋은 학원 같다" → **"우리 아이는 여기 보내야겠다"**. 모든 판단 기준은
"이 요소가 상담 신청률을 높이는가?" 하나다.

## 진단 — 기존 페이지가 전환을 잃던 지점

| 문제 | 내용 |
| --- | --- |
| 히어로 과밀 | 정보 카드 4개가 CTA를 첫 화면 밖으로 밀어냄 (특히 모바일) |
| 핵심 논리 매몰 | "미대는 성적순입니다"(최대 차별점)가 페이지 최하단 수강료 카드 안에 숨어 있었음 |
| CTA 부족 | 실질 CTA가 히어로 1회 + 하단 1회. 중간에 마음이 움직여도 신청 동선이 없음 |
| 사회적 증거 부재 | 후기 섹션이 아예 없었음 |
| 학부모 불안 방치 | 휴대폰·식사·안전 등 결정권자(학부모)의 1차 질문이 FAQ 아코디언 뒤에 숨어 있었음 |
| 설득 순서 역행 | 소개(트랙) → 논리 → 실적 순서라, 아직 안 궁금한 정보를 먼저 설명 |

## 새 섹션 순서 (설득 흐름)

1. **히어로** — 문제 제기("실기만 잘해서는 합격할 수 없습니다") + D-day·정원 14명 긴급성 + 즉시 CTA
2. **왜 학과인가** — "미대는 성적순" 논리를 최상단으로 승격, 일반 학원 비교
3. **왜 모다고인가** — 37년 누적 합격 실적 (숫자 증거)
4. → **CTA 밴드 #1** (차별점·실적 확인 직후)
5. **윈터캠프 소개** — 기간·대상·정원·마감 + 두 트랙
6. **생활관리** — 학부모 걱정 6문 6답 (휴대폰/식사/안전/아플 때/공부/소식)
7. → **CTA 밴드 #2** (불안 해소 직후)
8. **학과관리** (평일 전부) / **실기관리** (주말 집중) — 철학 순서대로 학과 먼저
9. **하루 일과표** / **시설 갤러리**
10. **후기** — 학부모(기본 탭)·학생·합격 3분류
11. → **CTA 밴드 #3** (사회적 증거 직후, 시즌 긴급성 카피)
12. **FAQ** — 남은 실무 질문만
13. **신청하기** — 폼을 섹션 최상단으로, 수강료·환불·오시는 길은 그 아래

## 주요 변경 상세

### 히어로
- H1: "실기만 잘해서는 / 합격할 수 없습니다" — 문제 제기형 카피로 교체
- 서브: "합격하는 학생은 학과도 준비합니다" + 8주 기숙 요약
- 정보 카드 4개 → 키워드 칩 6개로 경량화하고 CTA 위로 끌어올림.
  상세 정보는 [4] 소개 섹션으로 이동 → **모바일 첫 화면 안에 CTA 노출**
- 긴급성 배지 2종: D-day + "정원 14명 · 선착순 조기마감"
- CTA 아래 마이크로카피 "신청은 1분 · 밤에 남겨주셔도 다음 날 연락드립니다"로 행동 장벽 제거
- 히어로 backdrop-blur 카드 제거 → 렌더 비용 감소

### 새 컴포넌트
- `components/winter/CtaBand.tsx` — 섹션 사이 반복 배치용 CTA 밴드 (긴급성 문구 내장)
- `components/winter/Testimonials.tsx` + `lib/winter-testimonials.ts` —
  학부모/학생/합격 3분류 탭 후기. **기본 탭은 학부모** (결제 결정권자).
  현재 데이터는 전부 `[ ]` 자리표시자 — 실제 후기 수집 후 교체 필요 (TODO: 원장님 확인).
  `SHOW_TESTIMONIALS` 스위치로 섹션 전체 on/off 가능.

### 학부모 심리 (생활관리 섹션)
- 기존 "숫자로 보는 관리" + "안전 및 소통" 2개 섹션을
  **질문형 카드 6개**("휴대폰은 어떻게 하나요?" 등)로 통합.
  학부모가 실제로 묻는 문장을 제목으로 써서 FAQ 도달 전에 불안을 해소.

### 신청 섹션
- 상담 폼을 섹션 첫 요소로 승격 (기존에는 수강료 카드 아래).
- "미대는 성적순" 블록은 [2]로 이동해 중복 제거.
- 폼 테두리를 accent로 강조, 폼 상단에 정원·선착순 재노출.

### 애니메이션·성능
- fadeUp 이동거리 30→24px, duration 0.7→0.6s, stagger 0.1→0.05~0.06s로 감쇠.
- 기존 디자인 시스템(색·타이포·라운딩)·metadata·JSON-LD·SEO는 변경 없음.
